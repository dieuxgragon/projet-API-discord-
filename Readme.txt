Pour creer un super admin capable de lancer le serveur 
py manage.py createsuperuser :
il vous demandera un nom , un adresse mail et le mot de passe 
seul le pseudo et le mots de passe son obligatoire 

puis pour lancer le serveur executer la comande
py manage.py runserver
un lien cliquable apparaitra dans votre cmd pour allez sur le site sinon allez sur 
http://127.0.0.1:8000

si vous voulez tester le site sur insomnia/postman/swagger 
lancer le site avant
